# Kognis

Web aplikacija za učenje s Pomodoro timerom, quiz generatorom i praćenjem napretka.

## Tehnologije

- **Frontend:** React, Vite
- **Backend:** Django
- **Baza podataka:** SQLite

## Pokretanje

### Backend

```bash
cd backend
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Funkcionalnosti

- Registracija i prijava korisnika
- Pomodoro timer s praćenjem statistike
- Quiz generator
- Korisnički profil s bodovima
